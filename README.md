# SSC Study Studio — Native Android APK (Floating Transparent Dot)

## GitHub Actions se Free APK Kaise Banayein (Phone Chrome se):
1. `github.com` par naya repository banayein (jaise `ssc-study-studio-apk`).
2. Is zip ki saari files (`.github` folder sahit) upload karke **Commit** karein.
3. Upar **Actions** tab me jayein — 2-3 minute me green tick aa jayega.
4. Us build par click karke niche **Artifacts → SSC-Study-Studio-APK** download aur install karein.
5. App kholkar neeche ke glowing dot par tap karein → **Display over other apps** ON karein → ab app ke bahar real transparent floating dot chalega!
